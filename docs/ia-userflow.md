# remind — IA & User Flow

노션 학습노트를 문제로 복습하는 사이트. 사용자는 1명(본인), 데이터는 프론트(정적 파일 + localStorage).

---

## 1. 핵심 목표와 원칙

| 목표 | 설계 원칙 |
|---|---|
| 노트 내용을 빠짐없이 복습 | 모든 노션 소제목 = 개념 섹션 1개 = 문제 1개 이상 |
| 매일 짧게, 꾸준히 | 홈에서 "오늘 복습" 한 번 누르면 바로 시작 (탭 2번 이내) |
| 틀린 건 다시 나오게 | 간격 반복(Leitner 5단계) + 오답노트 |
| 주간 업데이트가 눈에 보이게 | 새로 추가·수정된 토픽에 NEW / UPDATED 배지 |
| 모바일 우선 | 하단 탭바, 한 손 조작, 버튼은 화면 아래쪽 |
| 디자인 시스템 준수 | `docs/design-system.md` (라이트 테마, 오렌지 브랜드, 쿨그레이 캔버스) |

## 2. IA (정보 구조)

```
remind
├── 홈  /
│   ├── 오늘 복습 카드 ──────────────→ 퀴즈 (복습 모드)
│   ├── 이번 주 업데이트 (NEW/UPDATED 토픽) → 토픽
│   ├── 트랙 카드 ×4 (진도율·정답률) ──→ 트랙
│   └── 이어서 풀기 (중단한 세션) ─────→ 퀴즈 (이어서)
│
├── 트랙  /track/:trackId          (frontend | backend | design | project)
│   ├── 트랙 요약 (토픽 수, 진도율, 정답률)
│   ├── 그룹 필터 칩 (예: 백엔드 = 전체·Python 기초·Flask·데코레이터·클래스·배포·MySQL·MongoDB·알고리즘)
│   └── 토픽 목록 (상태 배지, 문제 수, 정답률, 마지막 학습일) → 토픽
│
├── 토픽  /topic/:topicId
│   ├── 헤더 (트랙·그룹, 제목, 노션 원문 링크)
│   ├── [탭] 개념 ── 섹션 카드 목록 (핵심 문장 + 예시 코드), 섹션별 "이 부분만 풀기"
│   ├── [탭] 문제 목록 ── 문제별 상태(미풀이/정답/오답), 개별 문제 바로 풀기
│   └── 하단 고정 버튼: [전체 풀기] [틀린 것만]
│
├── 퀴즈  /quiz?mode=…&topic=…&section=…
│   ├── 진행바 (n / 전체), 나가기
│   ├── 문제 카드 (유형별 입력 UI)
│   ├── 채점 피드백 (정답/오답, 해설, 선택지별 설명, 출처 섹션 → 개념 보기)
│   └── 다음 문제
│
├── 결과  /quiz/result
│   ├── 점수, 소요 시간, 이번에 틀린 문제 목록
│   └── [틀린 것만 다시] [토픽으로] [홈으로]
│
├── 오답노트  /wrong
│   ├── 트랙 필터 / 토픽별 묶어보기
│   ├── 오답 카드 (문제, 내가 쓴 답, 정답, 틀린 횟수)
│   └── [오답 전체 풀기] [토픽별 풀기], 수동 삭제
│
└── 설정  /settings
    ├── 퀴즈 옵션 (문제 순서 섞기, 오늘 복습 최대 문제 수 — 기본 20)
    ├── 학습 기록 백업 (JSON 내보내기 / 가져오기), 초기화
    └── (나중) 비밀번호 잠금
```

### 전역 내비게이션
- 모바일: 하단 탭바 4개 — **홈 · 복습 · 오답노트 · 설정** (복습 = 오늘 복습 퀴즈 바로 시작)
- 태블릿·PC(≥768px): 같은 4개를 상단 헤더(높이 64)로. 콘텐츠 최대 너비 1200 (디자인 시스템 6장)
- 시안: 1440 / 768 / 390 (360에서 안 깨지는지 확인)
- 탭바는 최상위 화면(홈·오답노트·설정)에만. 트랙·토픽은 뒤로가기 헤더 + 하단 고정 CTA
- 퀴즈·결과 화면에서는 탭바 숨김 (집중 모드), 상단 [나가기]만
- 피그마: `📘 System Guide` · `🧩 Components` · `📱 Screens` 페이지 (https://www.figma.com/design/F9bo9j2bIabfqRtZW87ua2)

### 퀴즈 모드
| mode | 출제 범위 | 진입점 |
|---|---|---|
| `review` | 전체 트랙에서 오늘 복습할 문제 (due + 오답), 최대 N개 | 홈 오늘 복습, 탭바 복습 |
| `topic` | 토픽 전체 문제 | 토픽 [전체 풀기] |
| `section` | 토픽의 섹션 1개 문제 | 개념 탭 "이 부분만 풀기" |
| `wrong` | 오답노트 문제 (전체 / 트랙 / 토픽) | 토픽 [틀린 것만], 오답노트, 결과 |
| `single` | 문제 1개 | 문제 목록에서 개별 선택 |

## 3. 핵심 User Flow

### Flow A. 매일 복습 (가장 자주 쓰는 흐름)
```
홈 → [오늘 복습 시작] → 퀴즈(review)
   → 문제 풀기 ⇄ 채점·해설 (반복)
   → 결과 → [틀린 것만 다시] 또는 [홈으로]
```
- 오늘 복습할 문제가 0개면: "오늘 복습 끝! 새 토픽을 풀어볼까요?" + 미학습 토픽 추천

### Flow B. 새 토픽 처음 학습
```
홈 → 트랙 카드 → 트랙(그룹 필터) → 토픽
   → 개념 탭 읽기 → [전체 풀기] → 퀴즈(topic) → 결과
```
- 개념을 안 읽고 바로 [전체 풀기]도 가능 (강제하지 않음)

### Flow C. 틀린 문제 다시 보기
```
탭바 오답노트 → (트랙 필터) → [오답 전체 풀기] → 퀴즈(wrong) → 결과
```
- 오답노트 졸업: 오답 문제를 **연속 2번** 맞히면 자동으로 빠짐 (수동 삭제도 가능)

### Flow D. 이번 주 업데이트 확인
```
홈 '이번 주 업데이트' → NEW/UPDATED 토픽 → 개념 → 퀴즈
```
- UPDATED 토픽은 바뀐 섹션에 "업데이트됨" 표시, 그 섹션 문제만 풀기 가능

### Flow E. 중단 후 이어서
```
퀴즈 중 [나가기] → 확인 다이얼로그(진행 저장) → 이전 화면
홈 '이어서 풀기' → 같은 세션의 다음 문제부터
```

### Flow F. 백업/복원 (기기 변경·브라우저 초기화 대비)
```
설정 → [내보내기] → remind-backup-YYYYMMDD.json 저장
새 기기 설정 → [가져오기] → 파일 선택 → 덮어쓰기 확인 → 완료
```

## 4. 퀴즈 화면 상세 흐름 (문제 1개)

```
문제 표시
 ├─ 객관식  : 선택지 탭 → [제출]
 ├─ OX      : O / X 탭 → 즉시 채점
 ├─ 단답형  : 입력 → [제출] (공백·대소문자 무시 비교)
 └─ 서술형  : 입력(선택) → [모범답안 보기]
        ↓
채점 피드백
 ├─ 객관식/OX/단답 : 정답 ✅ / 오답 ❌ 자동 판정
 │    └─ 단답 오답일 때만 [정답으로 인정] (표현만 다른 경우 대비)
 ├─ 서술형 : 모범답안 + 키워드 표시 → 직접 채점 [알았음] [애매함] [몰랐음]
 ├─ 해설 (필수) + 객관식이면 선택지별 설명
 └─ 출처 섹션 링크 → 개념 시트(바텀시트로 열림, 퀴즈 이탈 없음)
        ↓
[다음 문제] (마지막이면 [결과 보기])
```
- 채점 결과 기록: 정답 → 박스 +1 / 오답 → 박스 0 + 오답노트 추가 / 서술형 "애매함" → 박스 유지

## 5. 학습 기록 모델 (localStorage)

```ts
// key: remind:v1:progress
{
  questions: {
    [questionId]: {
      box: 0 | 1 | 2 | 3 | 4 | 5,   // Leitner 단계
      nextDue: '2026-10-15',         // 다음 복습일
      correct: number, wrong: number,
      streak: number,                // 연속 정답 (오답노트 졸업 판정)
      lastAnswer?: string,           // 마지막으로 쓴 답 (오답노트 표시용)
      lastSeen: '2026-10-12',
    }
  },
  wrongNote: string[],               // 오답노트 문제 ID
  session?: { mode, ids: string[], index: number, results: {...}, startedAt }, // 이어서 풀기
  settings: { shuffle, dailyLimit },   // dailyLimit 기본 20
}
```
- 복습 간격(일): 박스 0→당일, 1→1, 2→3, 3→7, 4→14, 5→30
- 토픽 상태: **미학습**(푼 문제 0) / **학습중** / **완료**(모든 문제 1번 이상 풀고 정답률 ≥ 80%)
- 문제 ID가 고정이라 주간 업데이트 후에도 기록 유지. 삭제된 문제의 기록은 무시

## 6. 시스템 플로우: 주간 업데이트 (Claude가 수행)

```
"업데이트해줘"
 → 노션 학습노트 트리 조회
 → content/sync.json 과 비교 (페이지 ID + 마지막 수정 시각)
     ├─ 새 페이지   → 토픽 파일 생성 (status: new)
     ├─ 수정 페이지 → 바뀐 섹션만 문제 추가·수정, 기존 문제 ID 유지 (status: updated)
     └─ 삭제 페이지 → 토픽 숨김 (기록은 보존)
 → npm run build (콘텐츠 검사 포함) 통과
 → commit · push → Vercel 자동 배포
 → 변경 요약 보고 (+N 페이지, +M 문제)
```
- 토픽 데이터에 `updatedAt`, `changedSections` 필드 추가 → 홈 배지와 "업데이트됨" 표시에 사용
- 백엔드 트랙(알고리즘 제외)은 FastAPI·DB 자체 커리큘럼(web/py/fa/sa/as/au/sql/nq/dbd/pr)이다. 노션 백엔드 페이지가 수정되면 새 토픽을 만들지 말고, 섹션 `notionIds`로 그 페이지와 연결된 토픽의 섹션·문제를 갱신한다. 새 노션 페이지(예: FastAPI 강의 노트)도 먼저 관련 토픽 섹션에 연결할 수 있는지 본다.

## 7. 화면 목록 (피그마 작업 범위)

| # | 화면 | 상태 변형 |
|---|---|---|
| 1 | 홈 | 기본 / 오늘 복습 0개 / 첫 방문(기록 없음) / 이어서 풀기 있음 |
| 2 | 트랙 | 기본 / 그룹 필터 적용 |
| 3 | 토픽 | 개념 탭 / 문제 목록 탭 / UPDATED 섹션 표시 |
| 4 | 퀴즈 | 객관식 / OX / 단답 / 서술형 × (풀이 전, 정답, 오답) + 개념 바텀시트 + 나가기 다이얼로그 |
| 5 | 결과 | 오답 있음 / 만점 |
| 6 | 오답노트 | 기본 / 비어 있음 |
| 7 | 설정 | 기본 / 가져오기 확인 다이얼로그 |

## 8. 확정 사항
- 오늘 복습 최대 문제 수: 기본 20 (설정에서 변경)
- 토픽 완료 기준: 모든 문제 1번 이상 + 정답률 80% 이상
- 검색: 이번 범위 제외 (토픽 수가 늘면 추가)
- 테마: 라이트 전용 (디자인 시스템 기준)
- 반응형: 디자인 시스템 6장 브레이크포인트, 시안 1440 / 768 / 390

공통 컴포넌트: 하단 탭바, 상단 헤더, 버튼(Primary/Secondary/Ghost), 트랙 카드, 토픽 행, 상태 배지, 진행바, 선택지(기본/선택/정답/오답), 피드백 패널, 개념 섹션 카드, 코드 블록, 필터 칩, 다이얼로그, 바텀시트, 빈 상태
